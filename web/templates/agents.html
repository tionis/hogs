Workers

Workers connect prepared game-server hosts to HOGS and report their reachability and management capabilities.

Register a worker

  1. Install hogs-agent on the game-server host and give it a random shared secret.
  2. Expose its API over HTTPS and allow this panel's browser origin.
  3. Add the same worker ID, API URLs, and secret file to the HOGS control-plane configuration, then reload HOGS.
  4. Return here to verify reachability, then assign panel servers from each server's Settings tab.

Initial credentials are deliberately host-provisioned and are never accepted or displayed by this web page. See the Node Agent documentation distributed with HOGS for complete configuration examples.

Management workflow

A system administrator prepares a game server and adds its immutable server ID to the worker's local servers allowlist. An instance administrator then creates or opens that server in HOGS and assigns the matching worker from the server's Settings tab. Removing a panel assignment does not silently widen or rewrite the worker's host-level allowlist.
